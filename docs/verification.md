# Validation scope

Recorded on 2026-10-23 for Atlas Terminal 0.5.0 with Python 3.12.14 and Node.js 24.19.0 on Linux.

## Verified behavior

555 offline tests pass; two live tests are deselected. Default tests prohibit IP sockets and do not retrieve live sources or transfer funds.

Fifty-two new economic-history tests cover all 18 added series, bounded BLS POST chunks, earlier ECB observations/new currencies, exact prior-month/year inputs, BEA credential privacy, units/scales, BOJ date/value alignment, Dashboard indicator/dimension validation, date rejection, presets and shared interfaces. Four additional existing parametrized cases cover the two new datasets in whole-catalog and compact-evidence tests. New source fixtures are fictional; existing byte-exact fixtures are unchanged.

Forty payment-planning tests cover non-spending budget/preflight reads, policy denials, UTC-day and session accounting, changes between preflight and purchase, public-payer/signing-wallet mismatch, exact-query intent conflicts, concurrent publication, response loss, client commit rollback, restart, expiry/tombstones, capacity, secret redaction, old-server rejection, HTTP authorization and official MCP contracts. Preflight does not load a signing key or prove an on-chain balance. These tests use fictional sources and mocked settlement only.

SDK, HTTP, CLI and real stdio MCP exercise the same contracts. Every local OpenAPI reference resolves in the exported document; shared query schemas validate requests using component references. Diagnostic tests cover configuration-only operation without source clients/stores, private-contact redaction, fixture isolation, invalid network flags and actual probe logic against mock HTTP. Mock HTTP probe success is not live verification.

Research endpoints remain free of payment requirements in every payment mode. Mock-purchase checks cover authenticated recovery after an API restart. Wheel and sdist packages contain source fixtures and the Apache-2.0 LICENSE, without private runtime databases.

Source distributions explicitly select project paths and exclude installed dependencies, generated output and private state independently of VCS ignore behavior. `scripts/verify_distribution.py` checks source/wheel contents, package version, license and the Registry ownership marker before CI/release publication. A source archive rebuilt outside Git with a fictional `node_modules` directory passes the same archive checks, confirming the development dependency is excluded.

## Unverified behavior

Live SEC, BLS, Treasury, Federal Reserve, ECB, New York Fed, BEA, BOJ and Statistical Dashboard responses and runtime availability; real Base Sepolia transfers and reconciliation against a live RPC; and execution on Windows are unverified. ECB reference-rate documentation/conditions, New York Fed reference-rate terms and Treasury XML documentation were inspected for the macro/FX expansion. The NY Fed API documentation page could not be read fully; current terms for other sources and final dataset-specific redistribution checks remain unverified. Offline tests do not establish source availability, completeness, delivery latency or successful real settlement.

During this verification the current enforced outbound policy excluded all official data hosts, and no private SEC contact setting or BEA API key was configured. Live source checks remain NOT_RUN in this environment. The manual source-check workflow includes the new source probes but was not executed; it does not establish continuous monitoring or a new CI result. [Operator instructions and required hosts](source-checks.md).

No model-driven benchmark establishes task completion, tool-call reduction or token savings. Compact response tests compare fictional payload bytes and verify lossless provenance; they are not LLM evaluations.

`scripts/verify_installed.py` uses the installed package to check CLI, MCP, loopback HTTP, mock purchases and restart recovery without external requests or real transfers.

Run `scripts/verify_remote_installed.py` with the fresh installed wheel's Python interpreter to check the research-only Streamable HTTP process, official client and restart/evidence behavior on loopback. It uses packaged fixtures and creates a temporary private test token; it does not deploy a service or retrieve live observations.

Live checks in `scripts/research_smoke.py` and `scripts/smoke.py` require `--allow-network`. Real testnet transfers also require dedicated configuration and a transfer opt-in flag. Default CI does not run these checks.
