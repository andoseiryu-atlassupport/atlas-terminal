# Atlas Terminal support

Use the [GitHub issue tracker](https://github.com/andoseiryu-atlassupport/atlas-terminal/issues) for reproducible software, documentation and data-selection problems. Include the Atlas version, interface, provider, sanitized query, expected behavior and observed error code. GitHub issues are public.

For data-selection reports include the original publisher URL, series or CIK, filing accession if applicable, unit and actual observation period. Keep missing coverage distinct from transport failures. Synthetic examples must remain labeled fictional.

Do not include credentials, SEC contact settings, wallet material, signatures, private state databases, private portfolios or personally identifying request content. See [security reporting](../SECURITY.md), [privacy](privacy.md), [FAQ](faq.md) and [verification scope](verification.md).

The repository provides open-source issue tracking, with no response-time or data-availability SLA. No official public remote service or public ChatGPT plugin is currently operated. A self-hosted service's operator should publish their own support contact and operational terms.
